Herramientas PDF | Vinaròs

Manual de uso

1. Introducción

Herramientas PDF | Vinaròs es una plataforma completa para trabajar con archivos PDF directamente desde el navegador.

2. Interfaz principal

Buscador de herramientas: Permite localizar funciones rápidamente (atajo: Ctrl + K).

Listado de herramientas: Organizado por categorías.

Herramientas populares: Accesos rápidos personalizables por el usuario.

3. Herramientas populares (personalizables)

El usuario puede seleccionar y configurar sus herramientas más utilizadas para tenerlas siempre accesibles.

También dispone de la opción de restablecerlas a los valores predeterminados.

4. Herramientas principales

4.1 Herramientas básicas

Funciones más utilizadas:

  • Fusionar PDF
  • Dividir PDF
  • Comprimir PDF
  • Editor PDF
  • Reordenar, duplicar o eliminar páginas.
  • Rotar o dividir páginas.

4.2 Convertir a PDF

Convierte múltiples formatos a PDF:

  • Imágenes (JPG, PNG, SVG, etc.)
  • Documentos (Word, Excel, PowerPoint)
  • Archivos de texto (TXT, JSON, Markdown)
  • E-books (EPUB, MOBI)
  • Correos electrónicos

4.3 Convertir desde PDF

Exporta contenido PDF a otros formatos:

  • Imágenes (JPG, PNG, WebP)
  • Documentos (Word, Excel, CSV)
  • Texto y Markdown
  • JSON para uso en sistemas avanzados

5. Uso básico

  1. Selecciona una herramienta desde el buscador o el listado.
  2. Carga el archivo desde tu dispositivo.
  3. Configura las opciones según la función elegida.
  4. Ejecuta el proceso.
  5. Descarga el archivo resultante.

6. Consejos de uso

  • Verifica siempre el archivo final antes de compartirlo.
  • Mantén una copia del archivo original.
  • Usa compresión para archivos grandes.
